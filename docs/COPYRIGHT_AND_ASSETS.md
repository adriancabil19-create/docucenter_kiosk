### 3.1 ⚠️ Test artifacts committed to the repository — remove

The following look like **real test outputs containing document/transaction
content** and are tracked in git even though `.gitignore` lists the folders
(they were committed before the ignore rule and are therefore not ignored):

```
Uploads/b763d314-…​.pdf   + .meta.json
Uploads/eaa5d20c-…​.pdf   + .meta.json
PrintSimulation/…_receipt_JOB-*.pdf / .txt   (multiple)
PrintSimulation/1775591805140_scanned_1775591800243_0.png
backend/uploads/scanned_1775591607682_0.png
docucenter.db / docucenter.db-shm / docucenter.db-wal   (SQLite DB with transaction rows)
```

Keeping user documents and a live database under version control is a **data
minimisation / storage limitation problem under RA 10173**, and could expose
personal data if the repo is shared or published.

**Recommended action (does not delete your local working copies):**

```bash
git rm -r --cached Uploads PrintSimulation backend/uploads \
  docucenter.db docucenter.db-shm docucenter.db-wal \
  flutter_01.png scan.pdf query '$($type' \
  ntwain_datasource_members.txt ntwain_types.txt
# the .gitignore already covers Uploads/, PrintSimulation/, *.db — add:
#   backend/uploads/
#   /flutter_01.png
#   /scan.pdf
#   /query
git commit -m "chore: stop tracking test artifacts, DB, and user documents"
```

If any of those PDFs/PNGs contain another person's personal data, also purge
them from git history (`git filter-repo`) before the repo leaves the team.
